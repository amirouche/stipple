## V2 시스템 (3-tier)

**Tier 1: 명시적 매칭** (구체적 키워드)

- "김치찌개" / "양자역학" → 로컬 (비용 0, 빨간점)

**Tier 2: 모호한 입력 → LLM 의도 분류** (WebLLM 짧은 호출)

- "메뉴 추천" / "뭐 먹지" → WebLLM 분류 → 적절한 응답 형식
- 100ms, 사적 영역, 자연스러움

**Tier 3: 매칭 X → 일반 LLM 응답**

- "양자역학" → WebLLM/Gemini 정보 응답 (지금 동작)

## 학습 루프 단계

**단계 A** (1–1.5 시간): 자동 저장

- LLM 응답 → localStorage / IndexedDB
- 메타데이터: 입력, 응답, 컨텍스트, 시점, provider, voice/tone

**단계 B** (1–1.5 시간): 사용자 큐레이션

- "이 답 좋아 / 다른 거" 버튼
- 좋아요 받은 응답 → 매칭 우선
- 다른 거 클릭 → 다음 호출 시 다양성

**단계 C** (베타, 4–8 시간): LoRA adapter

- 사용자 데이터로 작은 모델 fine-tune
- 진짜 사적 AI

## 색상 의미 진화

- 빨간점 = 로컬 매칭 (학습 결과 포함)
- 초록점 = WebLLM (사적)
- 파란점 = Gemini (외부)

→ 시간 지날수록 빨간점 ↑, 파란점 ↓
→ "내 AI가 점점 나를 알아간다" 시각화
